# Bank Customer Credit Risk Analysis

**Business Analytics Dashboard | German Credit Dataset**

An end-to-end Business Analytics project using Python, PostgreSQL, SQL and Streamlit to analyse customer credit classifications and identify patterns across customer and loan segments.

## Project Overview

This project analyses 1,000 records from the UCI Statlog German Credit Dataset to understand recorded good and bad credit classifications.

## Key Performance Indicators

- Total Customers: 1,000
- Good Credit: 700
- Bad Credit: 300
- Bad Classification Rate: 30%

## Technologies Used

- Python
- Pandas
- PostgreSQL
- SQL
- Streamlit
- Plotly

## Key Analysis

- Credit classification distribution
- Average loan amount by classification
- Bad credit classification by age group
- Loan purpose analysis
- Customer credit-risk records

## Dataset

Source: [UCI Statlog German Credit Dataset](https://archive.ics.uci.edu/dataset/144/statlog+german+credit+data)

The Good/Bad labels represent recorded dataset classifications, not observed future loan defaults.

## How to Run

1. Clone the repository.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Configure PostgreSQL and load the cleaned dataset.
4. Run:

   `streamlit run app.py`
